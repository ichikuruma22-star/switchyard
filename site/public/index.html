PowerShell examples, with the CLI on your PATH.

Switchya CLI
# An interactive session
PS> switchya chat `
    --project C:\projects\my-project `
    --model MODEL

# A focused task
PS> switchya run `
    --project C:\projects\my-project `
    --model MODEL `
    --prompt "Explain the test failure"

Use an existing folder and a model ID from switchya models. For terminal-only use, close the desktop first.

Use your providers. Or your own agent setup.

The native engine uses Switchyard Gateway for model access. The Codex, Claude Code and Antigravity integrations connect to your own installations.

Named profiles keep each agent’s accounts separate. Codex, Claude Code and Antigravity conversations run inside the workspace; managed Claude Code and Antigravity profiles can also open in their own terminal.

Switchyard Gateway.

A standalone API gateway for your existing tools. Run it on your machine or server, add your provider credentials, and connect compatible clients to one endpoint.

Known limits

  • Portable ZIP for Windows 10/11 x64. It is unsigned, with no installer or bundled runtimes.
  • No macOS or Linux desktop download yet. Source is available on GitHub for other platforms.
  • Live checks have used an existing Codex CLI account and one managed Claude profile. Switching between accounts, and this release’s sign-in changes, have not been verified live.
  • Claude subscription quota isn’t shown, and Switchya can’t check Antigravity sign-in status.
